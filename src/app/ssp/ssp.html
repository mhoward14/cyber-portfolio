// HOW IT WORKS

The layout follows the sections of NIST SP 800-18 Rev. 1: system identification, categorization, environment and boundary, risk, control implementation, and the plan of action. The control baseline comes from the highest of the three FIPS 199 impact levels. If the RMF Tracker is set lower than that, the draft says so instead of quietly dropping controls.

Each implementation statement restates what the tracker records for the control and adds supporting configuration from the engagement where there is any. Where the tracker holds no note, the statement keeps a bracketed prompt. Roles, dates and target dates are never invented. A real SSP is written and approved by the people who run the system, so treat this as a head start, not a finished plan.
